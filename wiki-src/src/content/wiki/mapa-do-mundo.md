O mundo tem **mais de 280 mapas**. Cerca de um terço são **zonas seguras** (sem combate entre jogadores); o restante são **mapas PvP**.

## Regiões principais

| Região | Destaques |
|---|---|
| **Konoha e Arredores de Konoha** | vila inicial, Academia e as primeiras caçadas (Esquilo, Coelho, Ladrão, Bandido) |
| **Centro Acadêmico / Teste Genin / Treinamento Genin** | Iruka, Teste Genin e trocas de personagens com Pakkun e Tonton |
| **Divisão de estradas** | ponto de partida das estradas para as outras vilas |
| **Estrada pra Iwa → Vila da Pedra** | rota para Iwagakure |
| **Estrada pra Kiri** | rota para a Vila da Névoa |
| **Estrada pra Suna → Vila da Areia** | rota para Sunagakure |
| **Caminho pro CS → Chunin Shiken** | floresta e prédio do exame Chunin |
| **Floresta negra** | área de caça intermediária |
| **Estrada Vila do Som → Vila do Som** | território de Orochimaru |
| **Estrada pra Kumo → Vila da Nuvem** | rota para Kumogakure |
| **Bosque obscuro → Entrada Akatsuki → Vila da Chuva** | região da Akatsuki |
| **Arredores Takigakure → Vila da Cachoeira** | região de Takigakure |
| **País do Ferro** | região dos Samurais |
| **Hoshigakure / Vila Oculta Estrela** | vila da Estrela e suas missões |
| **Árvore Divina** | área de fim de jogo |
| **Mapas "Boruto"** | área de alto nível |

## Áreas especiais

| Área | Para que serve |
|---|---|
| **Área VIP** e **BOSS VIP** | mapas exclusivos de jogadores VIP |
| **Campo de Treino VIP (CT)** | sala de treino com passe CT — veja [Treinamento](/wiki/treinamento/) |
| **Arena Livre** e **Arena para Torneios** | lutas entre jogadores e torneios |
| **Desafio 1 a 5 e Desafio Final** | salas do evento de Desafios |
| **Esconderijo Akat** e **Esconderijo Oro** | covis de chefes que exigem chave |
| **Missão Rank S** | missão de alto nível que exige chave |
| **Centro de Trocas** | ponto de encontro para trocas |
| **Hospital** e **Sala do Hokage** | locais de NPCs de serviço |

## Mapas que exigem chave

Alguns mapas consomem um item-chave na entrada:

| Chave | Onde é usada |
|---|---|
| Akat no Key | covil da Akatsuki |
| Oro No Key | covil de Orochimaru |
| Chave Missão Rank S | Missão Rank S |
| Chave Roshi | área do Roshi |
| Chave Hoshigakure | Hoshigakure |
| Perg Estrela | mapa de upgrade da Estrela |

As chaves são obtidas em [missões](/wiki/missoes/), com [chefes](/wiki/chefes/) ou em [lojas](/wiki/moedas-e-lojas/).

## Viajando

- O **menu de viagem** leva direto para as vilas. **Konoha** é livre para todos; as demais vilas (Iwa, Kiri, Suna, Som, Kumo, Chuva, Takigakure, Vila do Ferro e Vila Estrela) são um benefício [VIP](/wiki/vip-e-beneficios/).
- Para viajar pelo menu é preciso estar com a **vida cheia** ou em uma **zona segura**.
