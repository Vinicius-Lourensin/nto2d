| Termo | Significado |
|---|---|
| **Bijuu** | Besta com Cauda — chefe poderoso ou invocação de Kage. [Ver mais](/wiki/bestas-com-cauda/) |
| **Bunshin** | clone de treino, usado no Teste Genin |
| **Cash** | moeda especial do jogo (item). [Ver mais](/wiki/moedas-e-lojas/) |
| **Chakra** | energia do personagem (os jutsus não gastam chakra; os mais fortes têm recarga maior) |
| **Recarga** | tempo de espera até poder usar o mesmo jutsu de novo |
| **Char fixo** | item que libera um personagem para sempre pelo comando `/nome` |
| **CS (Chunin Shiken)** | exame que promove Genins a Chunin |
| **CT** | passe temporário para o Campo de Treino VIP. [Ver mais](/wiki/vip-e-beneficios/) |
| **Desertor** | rank de quem entra em Akatsuki, Taka ou Espadachins da Névoa |
| **Dojutsu** | técnica ocular ou especial temporária (Sharingan, Byakugan, Modo Sábio) que libera jutsus |
| **Drop** | item deixado por um monstro ao ser derrotado |
| **Frag** | fragmento de personagem — pergaminho que transforma no personagem |
| **Hotbar** | barra de atalhos com 12 espaços |
| **Jutsu** | técnica ninja usada com chakra. [Ver mais](/wiki/jutsus/) |
| **Karma** | pontuação de PvP que separa Heróis (positivo) e Assassinos (negativo) |
| **KS (Kage Shiken)** | torneio que define o Kage de cada vila |
| **Lendário** | vencedor do evento Elite Shinobi |
| **Líder** | "Kage" de uma vila conquistado por um Desertor |
| **Nin** | personagem de estilo Ninjutsu (mais chakra) |
| **Org** | organização. [Ver mais](/wiki/grupos-e-organizacoes/) |
| **Party** | grupo de até 4 jogadores |
| **PK** | modo que permite atacar outros jogadores. [Ver mais](/wiki/pk-e-pvp/) |
| **PvP** | combate entre jogadores |
| **Reset** | volta ao level 1 com recompensas, no level 1000. [Ver mais](/wiki/reset/) |
| **Stun** | paralisia: o alvo não anda nem ataca |
| **Sumon** | pergaminho ou jutsu de invocação |
| **Tai** | personagem de estilo Taijutsu (mais HP) |
| **TIP** | Torneio Inner Power, torneio de lutas 1x1 |
| **Trans** | transformação, liberada por level |
| **VIP** | benefício temporário que dá mais EXP e outras vantagens |
| **Vocação** | cada personagem da sua coleção, com level próprio |
| **Yen** | moeda básica do jogo (item) |
| **Zona segura** | mapa onde não há combate entre jogadores |
